## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 压接作业手法差异 | 排除：压接剖面合格 |
| 机 | 压接工装磨损 | 排除：工装点检记录正常 |
| 料 | 端子弹性材料批次差异 | **成立：新批次回弹量偏低** |
| 法 | 插拔力进料抽检频次不足 | **成立：仅首件抽检** |
| 环 | 试验室温湿度 | 排除：受控 |
| 测 | 联调台架接地干扰 | 排除：更换通道复测无改善 |

### 4.2 5Why 分析链

信号闪断 → 端子正压力不足接触不稳 → 端子弹性材料回弹量低于规范 → 供应商更换簧片材料供应商未重新送样认证 → 变更管理流程对材料级变更未强制重测。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 簧片材料批次回弹量不足，正压力低于标准 | 材料金相与插拔力实测 |
| 流出原因 | 插拔力进料检验仅首件抽检，未覆盖批次波动 | 进料检验记录 |
| 系统原因 | 供应商变更管理协议未约定材料级变更重测要求 | 变更追溯记录 |
