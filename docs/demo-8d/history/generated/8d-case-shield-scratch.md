## D2 问题描述（5W2H）

- **What（什么问题）**：屏蔽罩压装后角部翘起变形，其中 2 块板变形刃边划伤下方 0402 阻容元件本体，划伤深至基材，绝缘可靠性存疑。
- **When（何时发生）**：2025-06-09 白班，压装后 AOI 复看图像时首次发现 1 例，随后触发批次全检。
- **Where（何处发生）**：屏蔽罩压装工序（P5 工位）→ 压装后 AOI 工位检出。
- **Who（谁发现）**：AOI 操作员复看图像报检，检验员 A 复判确认。
- **Which（影响对象）**：ZK-C3 主控板，屏蔽罩左后角集中，翘起方向一致。
- **How detected（如何检出）**：AOI 2D 图像发现明显翘起 → 批次全检外观 + 高度仪复测角部翘起量 → 显微镜确认元件本体划伤。
- **How many（数量/比例）**：不合格 10 块 / 批次总数 200 块，不合格率 5.0%；其中 2 块伴随元件划伤。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 操作未按 SOP 放件 | 排除：放件动作与监控记录一致 |
| 机 | 压装机压力异常 | 排除：压力曲线实测 850±40 N，处于窗口内 |
| 工装 | 定位销磨损 | **成立：左后角定位销实测 Ø5.85 mm，磨损 0.15 mm，配合间隙达 0.20 mm** |
| 料 | 屏蔽罩来料平面度不良 | 排除：同批来料检验合格，不良与来料批无相关性 |
| 法 | 压装压力/行程参数不当 | 排除：参数与工艺评定一致 |
| 测 | AOI 误判 | 排除：实物测量证实真实变形与划伤 |

### 4.2 5Why 分析链

角部翘起并划伤下方元件 → 压合压力中心偏移至单角（实测左后角受力占比 61%）→ 屏蔽罩放入后定位偏斜 → 定位销磨损 0.15 mm、间隙超差（该工装累计压装约 6.8 万次未更换）→ 工装易损件无寿命台账与强制更换周期，仅依赖目视判断更换。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 定位销磨损 0.15 mm 致屏蔽罩偏斜，压合力偏向一角，局部应力集中造成角部翘起及刃边刮蹭 | 拆检实测数据 + 压力分布复现试验 |
| 流出原因 | 压装后仅按 AQL 抽检外观，AOI 程序无四角翘起高度检测项，角部翘起与划伤位于视觉死角 | 检验规范条款 + AOI 程序核查 |
| 系统原因 | 工装易损件无寿命台账、无强制更换周期管理要求 | 《工装管理制度》缺项 |

## D6 实施与效果验证

- 验证方法：复产后续 3 批（共 600 块）四角高度 100% 自动检测 + 每批抽 3 块高度仪复测；定位销磨损量按每万次抽测监控。
- 验证数据：四角最大翘起 0.06 mm（限值 0.10 mm），元件划伤 0 例；压力分布复测四角受力偏差 ≤3%（整改前 61% 单角集中）；定位销 3 万次抽测磨损 0.02 mm，趋势正常。
- 判定：连续 3 批零复发，措施有效；压装后全检经评审回调为四角自动检测 100% 覆盖 + 外观按 AQL 抽检。
