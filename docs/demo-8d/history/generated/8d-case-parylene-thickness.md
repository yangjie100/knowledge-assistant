## D2 问题描述（5W2H）

- **What（什么问题）**：三防涂覆后检查发现 J2 插头防护区三防漆覆盖并流入接触件插针部位；测厚仪复测局部干膜厚 120μm，超出 30–80μm 标准，隐患为接触电阻增大、插合导通失效。
- **When（何时发生）**：2025-06-18 白班涂层测厚抽检工位首次检出。
- **Where（何处发生）**：三防涂覆工序（S2 选择性喷涂线）→ 测厚/荧光检查工位检出。
- **Who（谁发现）**：测厚操作员报检，检验员 C 紫外灯下复判确认。
- **Which（影响对象）**：ZK-C3 主控板，J2 矩形插头（16 芯）防护区集中。
- **How detected（如何检出）**：测厚抽检发现插头邻近点超厚 → 365nm 紫外荧光检查确认接触件覆漆 → 插合模拟测试接触电阻由 ≤5mΩ 增至 28mΩ，隐患坐实。
- **How many（数量/比例）**：不合格 3 块 / 批次总数 72 块，不合格率 4.2%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 未按喷涂参数卡执行 | 排除：喷涂机参数与运行记录一致 |
| 机 | 遮蔽夹具变形 | **成立：J2 遮蔽裙边翘曲实测 0.9mm（要求 ≤0.2mm），贴合不严，漆雾渗入** |
| 料 | 三防漆批次粘度异常 | 排除：粘度实测 26s（涂-4 杯）在窗口内，同批漆他线使用正常 |
| 法 | 喷枪折返点叠加、固化前无流平检查 | **成立：往复折返点位于插头区，2 道次叠加致局部膜厚达 120μm** |
| 环 | 喷房温湿度异常 | 排除：25℃/55%RH 记录受控 |
| 测 | 检测覆盖不足（流出侧） | **成立：见 4.3 流出原因** |

### 4.2 5Why 分析链

漆液流入接触件且局部膜厚 120μm → 插头遮蔽裙边与板面贴合不严、折返区漆雾叠加渗入 → 遮蔽夹具经长期喷涂—80℃ 固化温度循环后裙边累积变形 → 工装仅作外观目视点检、无定期变形量检测要求 → 《涂覆工装管理办法》缺少变形检验周期与判废标准。

（流出链：测厚固定 5 点未含插头边缘 + 荧光检查按 AQL 抽检 → 超厚与覆漆缺陷未能在工序内全数拦截。）

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 遮蔽夹具变形致贴合不严，喷枪折返区喷雾叠加，固化前未设流平检查 | 夹具实测变形量、膜厚分布测绘 |
| 流出原因 | 测厚抽检固定 5 点未覆盖插头边缘；荧光检查为抽检 | 检验规程条款与抽检记录 |
| 系统原因 | 遮蔽工装无定期变形检查要求 | 《涂覆工装管理办法》缺项 |

## D5 永久纠正措施（PCA）

| 序号 | 针对原因 | 措施 | 责任 | 期限 |

| 2 | 流出原因 | 测厚点网格化由固定 5 点增至 12 点（3×4），覆盖插头边缘及大件阴影区；荧光检查由抽检改为批产全检并纳入检验规程 | 质量部 | 06-30 |
| 3 | 系统原因 | 《涂覆工装管理办法》增补遮蔽工装每季度（或每 200 次使用循环）变形量检测（≤0.2mm）与寿命判废条款，建立工装台账 | 工艺室 | 07-02 |

## D6 实施与效果验证

- 验证方法：后续连续 3 批（共 216 块）荧光全检 + 12 点网格测厚 + 每批抽 3 块作插头插合接触电阻测试。
- 验证数据：接触件覆漆 0 例；干膜厚分布 42–74μm，100% 处于 30–80μm 窗口；接触电阻实测 2.1–4.6mΩ（要求 ≤5mΩ）；硅胶护套累计使用 60 次无变形。
- 判定：连续 3 批零复发，措施有效；荧光全检与 12 点网格测厚固化为该型号例行检验要求。
