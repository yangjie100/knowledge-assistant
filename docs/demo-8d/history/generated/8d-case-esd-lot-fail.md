## D2 问题描述（5W2H）

- **What（什么问题）**：ICT＋功能测试发现 DCDC 芯片功能失效，EMA 确认失效点为输出使能（EN）脚输入保护结构栅氧化层击穿。
- **When（何时发生）**：2024-11-06 白班功能测试工位首次批量检出。
- **Where（何处发生）**：SMT 贴装工序（A2 线）引入损伤 → ICT＋功能测试工序检出。
- **Who（谁发现）**：功能测试操作员报检，检验员 C 复判确认。
- **Which（影响对象）**：ZK-B2 电源模块 U3 位号 DCDC 芯片，失效集中于输出使能脚，芯片均为日期码 2442 同一批。
- **How detected（如何检出）**：功能测试 EN 脚控制失效 → ICT 管脚隔离定位 → EMA 光辐射显微 + 化学开封剥层，确认栅氧化层击穿。
- **How many（数量/比例）**：不合格 27 块 / 批次总数 450 块，不合格率 6.0%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 贴装/测试人员静电防护执行不到位 | 排除：腕带日检记录与接地系统实测均合格 |
| 机 | 贴片机、回流焊设备静电损伤 | 排除：设备接地电阻与离子风机平衡电位实测合格 |
| 料 | 芯片本体 ESD 防护能力异常 | **成立：该日期码批 HBM 实测 ±900 V 即失效，远低于规格 ±2000 V** |
| 法 | 产线按常规等级（适用 HBM ≥±2000 V 器件）管控，未识别敏感批次差异 | 成立：与料因叠加致损伤 |
| 环 | 车间温湿度异常 | 排除：RH 45%～55%，记录处于受控范围 |
| 测 | 测试夹具/程序误判 | 排除：失效品复测与 EMA 结果相互印证 |

### 4.2 5Why 分析链

EN 脚功能失效 → 使能脚栅氧化层击穿 → 栅极承受超防护能力静电应力 → 该批芯片 ESD 防护降级（供应商将栅氧生长改为快速热氧化，氧化层厚度由 12.5 nm 减至 9.0 nm）→ 供应商工艺变更未发 PCN，来料等级未更新 → 我方 PCN 接收与评审流程未闭环。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 该日期码批芯片 ESD 防护等级降级至 ±900 V，产线防静电仍按常规等级管控，贴装/测试过程静电应力击穿使能脚栅氧 | 供应商 8D 回复函 + 我方 HBM 鉴别对比试验（GJB 548 方法 3015） |
| 流出原因 | 来料检验仅外观与功能抽测（AQL 0.65），未覆盖 ESD 敏感度批次差异，降级批直接上线 | 《来料检验规范》相应条款 |
| 系统原因 | 供应商 PCN 接收与评审流程未闭环，变更信息未传递至来料等级与产线防护要求 | 《供应商变更管理规程》缺强制评审节点 |

## D6 实施与效果验证

- 验证方法：换料复产后连续 3 批（共 1350 块）ICT＋功能测试全检，每批抽 8 块进行 EN 脚 IV 特性复测与 HBM ±1500 V 步进摸底。
- 验证数据：DCDC 功能失效 0 例；换料批 HBM 实测通过 ±2200 V；专区湿度连续记录处于 30%～40%RH；PCN 评审台账自 11-25 起无缺项。
- 判定：连续 3 批零复发，措施有效，来料 ESD 抽测项转入常规检验规范执行。
