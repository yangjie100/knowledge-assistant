## D2 问题描述（5W2H）

- **What（什么问题）**：整机联试发现 ZK-A5 接口板一路备用通道（CH8-B）增益实测 20.1 dB，超出 17.1±1.0 dB 要求；该通道为 C 版改版新增，单板电测程序未含其测试项，缺陷未经工序拦截。
- **When（何时发生）**：单板电测完成于 2025-06-13（结果“合格”），2025-06-16 整机联试阶段首次检出。
- **Where（何处发生）**：缺陷源于贴装/电测工序（ZK-A5 专用电测工位）→ 整机联试（联试大厅 2 号台位）检出。
- **Who（谁发现）**：整机联试测试员报障，联试设计师复测确认，质量部当日立案。
- **Which（影响对象）**：ZK-A5 接口板组件 C 版，备用通道 CH8-B 增益电路（反馈电阻 R78）。
- **How detected（如何检出）**：整机增益自标定超差告警 → 单板回台复测复现 → 调取电测程序与最新原理图比对，确认程序点位表仍为 B 版。
- **How many（数量/比例）**：批次全数 60 块，备用通道加测后确认超差 3 块，不合格率 5.0%；其余 57 块复测合格。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 电测操作员漏测备用通道 | 排除：程序 V2.03 本身无该项，非操作问题 |
| 机 | 电测设备精度漂移 | 排除：校准在有效期内，标准样件复核偏差 ≤0.1 dB |
| 料 | 增益电阻用错规格 | **成立：R78 应为 6.20 kΩ，实装 9.10 kΩ（同封装丝印易混），理论增益偏高约 2.9 dB，与实测吻合** |
| 法 | 测试程序未随硬件改版同步更新 | **成立：ECO-2025-031（C 版新增 CH8-B）发布后，程序仍为基于 B 版点位表的 V2.03，新通道测试项缺失** |
| 环 | 车间温湿度影响 | 排除：环境记录在受控范围 |
| 测 | 程序与图纸版本无关联性检查 | **成立：程序放行评审记录中无原理图版本核对项，且无硬件设计会签** |

### 4.2 5Why 分析链

整机联试备用通道增益超差 → 单板电测未覆盖 CH8-B 通道 → 电测程序沿用 B 版点位表 → ECO 改版信息未传递至测试程序环节（程序工程师未接到变更通知）→ 《设计变更控制程序》未将“测试影响性分析与测试程序版本确认”设为 ECO 闭环强制节点，变更传递链存在断点。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | C 版改版新增备用通道未同步纳入电测程序，通道增益超差（R78 用错规格）未经单板电测检出 | 程序版本与 ECO 履历、电阻实测数据 |
| 流出原因 | 测试程序与原理图版本间无关联性检查要求，程序版本评审无硬件工程师会签，覆盖率确认环节缺失 | 《电测程序管理细则》条款与放行记录 |
| 系统原因 | ECO 到测试程序的传递链无强制闭环，测试影响性分析为可选动作 | 《设计变更控制程序》流程节点核查 |

## D6 实施与效果验证

- 验证方法：后续 3 批（P2025-0625-01、P2025-0702-01、P2025-0709-01，共 180 块）按 V2.10 程序电测全检，备用通道 100% 覆盖；每批抽 2 块随整机联试验证。
- 验证数据：3 批电测一次通过率 100%，备用通道增益实测 16.6~17.4 dB，全部处于 17.1±1.0 dB 内；程序-图纸版本校验记录 100% 完整；整机联试增益标定一次通过，零复发。
- 判定：连续 3 批零复发，V2.10 程序与放行检查流程有效，措施确认关闭。
