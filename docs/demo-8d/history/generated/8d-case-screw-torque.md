## D2 问题描述（5W2H）

- **What（什么问题）**：整机接地电阻测试超差（标准 ≤10mΩ，实测 42~88mΩ），拆解确认 4×M5 接地螺钉力矩不足（残余力矩 1.6~2.8N·m，工艺要求 4.5±0.5N·m），汇流条与机壳搭接面压力不足。
- **When（何时发生）**：2024-05-21 白班成品测试时首次检出，不良集中于当日装配的第 35~55 台区间。
- **Where（何处发生）**：总装车间 A2 工位（接地螺钉装配）→ 整机测试工位（接地电阻测试）检出。
- **Who（谁发现）**：测试操作员报检，检验员 A 复判确认并扩大检测。
- **Which（影响对象）**：ZK-E1 整机接地汇流条—机壳搭接部位。
- **How detected（如何检出）**：成品抽检抽中 1 台超差（88mΩ）→ 批内全检 → 累计 8 台 → 拆解进行残余力矩复核。
- **How many（数量/比例）**：不合格 8 台 / 批次总数 60 台，不合格率 13.3%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 未按对角顺序施拧 | **成立（促成）**：现场观察 3 名操作员中 2 人施拧顺序随意 |
| 机 | 电动螺丝刀力矩漂移 | **成立（主因）**：设定 4.5N·m，实测输出仅 2.1~2.3N·m |
| 料 | 螺钉/汇流条镀层异常 | 排除：接触面状态正常，同批物料他线使用正常 |
| 法 | SOP 缺对角施拧图示、无班前校验要求 | **成立（管理缺陷，归入系统原因）** |
| 环 | 车间温湿度异常 | 排除：环境记录在受控范围 |
| 测 | 接地电阻测试仪误差 | 排除：仪器检定有效期内，换表复测数据一致 |

### 4.2 5Why 分析链

主链：接地电阻 42~88mΩ 超差 → 搭接面接触压力不足 → 螺钉实际力矩仅 1.6~2.8N·m → 电动螺丝刀离合器磨损、输出力矩漂移至 2.1N·m → 上次标定（04-19 合格）后连续使用 22 个工作日无日常校验手段，漂移未被及时发现 → 管理规程缺班前校验与短周期核查要求（系统漏洞）。

并行促成链：未按对角顺序施拧 → 搭接面单侧先压紧、涂层刺破不完全 → 有效压接面积减小，接触电阻进一步升高。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 电动螺丝刀离合器磨损致输出力矩漂移至 2.1N·m（低于工艺下限 4.0N·m），叠加未按对角顺序施拧，搭接面压力不足 | 工具实测数据、拆解残余力矩、现场观察记录 |
| 流出原因 | 接地电阻执行“首件＋批抽检（5%，3 台）”，首件合格无法覆盖批产中段的力矩衰减区间 | 《成品检验规范》条款、不良分布区间 |
| 系统原因 | 《力矩工具管理规程》月度（30 天）标定周期过长，且无班前校验要求；装配 SOP 缺对角施拧图示 | 规程与 SOP 文本核查 |

## D6 实施与效果验证

- 验证方法：返修机复测＋后续 3 批（P2024-0522-01、0527-01、0603-01，共 165 台）接地电阻全检；班前校验记录连续审查 25 个工作日；施拧顺序 3 次飞行检查。
- 验证数据：8 台返修机复测 1.5~3.6mΩ 合格；后续 3 批实测 1.8~4.6mΩ，超差 0 例；12 把工具班前校验偏差均 ≤±5%；对角施拧执行率 100%。
- 判定：连续 3 批零复发，力矩漂移具备日常监控手段，措施有效；全检按规范常态执行。
