## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 点胶参数误设 | 排除：程序参数与参数卡、设定记录一致 |
| 机 | 点胶针头微堵致胶径衰减 | **成立：拆检针头见固化胶渣，胶点直径由 0.52 mm 逐板衰减至 0.30 mm** |
| 料 | 贴片胶批次黏度异常 | 排除：同批胶他线正常，黏度实测 45 Pa·s 在规定范围 |
| 法 | 贴片吸嘴压力固定、未随胶径联动补偿 | **成立：压力固定 2.0 N，胶量不足时胶体铺展不足，粘接面积下降** |
| 环 | 车间温湿度异常 | 排除：当班记录 23±2 ℃、55%RH，受控 |
| 测 | AOI 误报 | 排除：复判与推力试验证实真实移位 |

### 4.2 5Why 分析链

B 面大片电容二次回流时移位脱离焊盘 → 固化胶粘接强度不足 → 胶点直径衰减至 0.30 mm、胶量不足 → 点胶针头内固化胶渣累积造成微堵、出胶量逐板下降 → 针头清洗周期为每班次一次，长时间连续点胶后胶渣无法及时清除 → 关键工艺参数（胶点直径）无班中自动检测闭环，衰减趋势不能被及时识别与拦截。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 针头微堵致胶点直径衰减（低于下限 0.15 mm）；贴片压力固定未联动补偿，胶体铺展不足，粘接强度下降 | 针头拆检记录、胶径逐板实测数据 |
| 流出原因 | 点胶后无胶点直径检测工序，缺陷依赖回流后 AOI 事后检出，未能在点胶工序内拦截 | 检验流程文件缺项 |
| 系统原因 | 点胶设备关键工艺参数无班中自动检测闭环，《SMT 工艺控制程序》未规定胶点直径过程监控要求 | 程序文件评审记录 |

## D6 实施与效果验证

- 验证方法：整改后连续 3 批（共 420 块）胶点直径 CCD 全程监控＋回流后 AOI 100% 检查，每批抽 3 块做电容粘接推力试验（判定值 ≥15 N）。
- 验证数据：胶点直径稳定在 0.48～0.54 mm；电容移位 0 例；推力实测 22～28 N（均值 24.5 N），全部合格；AOI 移位类报警 0 次。
- 判定：连续 3 批零复发，措施有效，经评审确认转入常态化监控。
