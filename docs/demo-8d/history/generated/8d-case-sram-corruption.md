## D2 问题描述（5W2H）

- **What（什么问题）**：整机联试期间偶发参数区数据丢失，关键配置参数（备份 SRAM 存储，共 128 字节）在上电后校验出错，累计 3 次/200h；示波器时序分析确认上电瞬间写入窗口异常。
- **When（何时发生）**：2025-05-18，整机联试 200h 考核段内首次检出并累计确认。
- **Where（何处发生）**：整机联试（电源扰动联试项目）检出，缺陷源自软件联调工序交付的固件 V2.11 与电源上电时序配合缺陷。
- **Who（谁发现）**：联试监控岗报出参数校验错告警，软件工程师复现确认。
- **Which（影响对象）**：ZK-D1 信号处理板 2 台样机，备份域参数区写入流程。
- **How detected（如何检出）**：联试监控日志参数 CRC 校验错 → 台架快速上电循环复现 → 示波器抓取主电源与备份域上电时序定位。
- **How many（数量/比例）**：整机联试 3 次/200h；台架复现试验中断电后 50ms 内重新上电 20 次循环，出现 5 次数据丢失，复现率 25%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 联调人员操作不当 | 排除：联试操作与大纲一致 |
| 机 | 电源模块输出异常 | 排除：模块单测合格，上电速率在规格内（主 3.3V 约 2ms 建立，备份域经软启动约 8ms 建立，速率差为设计固有） |
| 料 | 备份电容/电池批次差异 | 排除：换批对比复现率无变化 |
| 法 | 固件上电流程缺陷 | **成立：复位释放后约 5ms 即执行参数回写，早于备份域建立，且未查询电源稳定标志** |
| 环 | 温度/电磁干扰 | 排除：温箱与屏蔽条件下复现率不变 |
| 测 | 联试用例覆盖不足 | **成立：用例库无快速上电循环项（间隔＜50ms），常规用例（间隔≥1s）全部通过** |

### 4.2 5Why 分析链

参数区数据丢失 → 上电瞬间 CPU 向备份 SRAM 写入 → 写入发生在备份域保持电压建立之前 → 固件上电流程未等待电源稳定标志即启动参数回写 → 软件设计输入缺少电源时序最小上电间隔约束 → 电源时序表未作为设计规范传递至软件设计与测试用例。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 主电源上电速率快于备份域，CPU 在 SRAM 保持电压建立前发起写入，写入落入无效窗口 | 示波器时序捕获：主电源 2ms/备份域 8ms，写入发起于上电后 5ms |
| 流出原因 | 联调用例未覆盖快速上电循环（间隔＜50ms），常规间隔用例通过，缺陷未拦截 | 《联试用例库》V3.2 目录核查 |
| 系统原因 | 电源时序设计文件仅规定各路电压建立顺序，未定义最小上电间隔/备份域建立时间约束并传递至软件与测试 | 《电源时序表》及设计输入清单缺项 |

## D6 实施与效果验证

- 验证方法：2 台样机换装固件 V2.13 与优化后电源板，执行快速上电循环考核（20/50/100ms 间隔各 100 次，共 300 次循环）；恢复整机联试补充考核 300h（含 20 次随机断电上电）。
- 验证数据：快速循环参数区校验差错 0 次；整机联试 300h 数据丢失 0 次；时序复测显示写入发起时刻均晚于备份域稳定标志置位，最小裕量 46ms。
- 判定：连续验证零复发，措施有效，解除联试断电间隔操作限制，冻结的 12 块板卡刷写新固件后放行。
