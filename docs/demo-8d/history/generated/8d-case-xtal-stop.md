## D2 问题描述（5W2H）

- **What（什么问题）**：高低温试验 -40 ℃ 工作段，受试样机主时钟（25 MHz 无源晶振）停振、时钟信号丢失，恢复常温后功能自行恢复；低温下以串联电阻法实测晶振引脚，确认振荡回路负阻裕量不足。
- **When（何时发生）**：2025-06-17，环境试验室 -40 ℃ 保温 1.5 h 后功能巡检时首次检出。
- **Where（何处发生）**：缺陷在功能测试＋高低温环节暴露；涉及工序为 SMT＋回流（负载电容贴装位 C13/C14）；根源位于时钟电路设计选型。
- **Who（谁发现）**：试验员巡检报检，测试工程师低温复测确认，检验员 A 复判。
- **Which（影响对象）**：ZK-C3 主控板，主时钟电路（晶振 G1，CL=8 pF，ESR≤50 Ω）。
- **How detected（如何检出）**：-40 ℃ 功能巡检发现无时钟输出 → 常温复测恢复正常 → 低温下示波器观测起振过程并用串联电阻法测负阻裕量。
- **How many（数量/比例）**：试验抽样 12 块中 4 块失效（33.3%）；全批 200 块低温筛查累计 7 块异常（3.5%）。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 贴片换料、程序调用错误 | 排除：换料记录与首件核对一致 |
| 机 | 回流温度曲线异常损伤晶振 | 排除：炉温曲线复核合格，焊点外观正常 |
| 料 | 电容/晶振来料参数偏差 | 排除：电容实测 12 pF 与 BOM 一致，晶振同批留样电参数合格 |
| 法 | 负载电容选值未匹配晶振 CL | **成立：12 pF 选值沿用上一代晶振参数，与本型 CL=8 pF 失配，负阻裕量低温不足** |
| 环 | 试验箱温度过冲 | 排除：箱体校准有效，记录曲线受控 |
| 测 | 常温功能测试无法覆盖低温特性 | **成立：测试大纲未含低温裕量项，形成流出通道** |

### 4.2 5Why 分析链

低温时钟丢失 → -40 ℃ 时振荡回路负阻 |-R|=88 Ω 低于晶振等效串联电阻 92 Ω，负阻裕量归零 → 负载电容选值偏大（12 pF），低温下驱动负阻下降、ESR 上升 → 设计时仅做常温负阻估算且沿用旧选型，未做全温区裕量计算 → 时钟电路设计检查单无负阻裕量计算强制项，设计评审未拦截。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 负载电容选值偏差致振荡回路负阻裕量在 -40 ℃ 低于晶振 ESR | 常温 |-R|=155 Ω（3.7×ESR）表观合格；-40 ℃ 实测 88 Ω＜ESR 92 Ω |
| 流出原因 | 常温功能测试全通过，低温特性未覆盖；首件未做低温负阻裕量验证 | 测试大纲与首件记录缺项 |
| 系统原因 | 《时钟电路设计检查单》无负阻裕量计算强制项 | 检查单现行版本条款核查 |

## D6 实施与效果验证

- 验证方法：返修后 200 块全数常温功能测试；抽 20 块做 -40 ℃/+70 ℃ 高低温工作试验；抽 5 块做低温负阻实测与频偏检测。
- 验证数据：高低温试验 0 例时钟丢失；-40 ℃ 负阻均值 305 Ω，对 ESR 92 Ω 裕量 3.3×（≥3×合格）；改值后频偏 -3 ppm（要求 ±20 ppm）；后续 3 批共 480 块低温抽测 0 复发。
- 判定：连续 3 批零复发，措施有效，返修批准予放行。
