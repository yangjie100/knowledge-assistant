## D2 问题描述（5W2H）

- **What（什么问题）**：ZK-A5 接口板组件离子污染度实测 1.8 μgNaCl/cm²（技术条件要求 ≤1.5），呈批次性偏高；追加盐雾试验（96 h）后微观检查确认导通/绝缘相邻区域出现电化学迁移树枝晶。
- **When（何时发生）**：2025-06-16 例行周检首次检出，追溯确认清洗过程异常始于 06-10 白班树脂补液后。
- **Where（何处发生）**：清洗工序（W7 清洗线）→ 离子污染度测试工位检出。
- **Who（谁发现）**：周检测试操作员报检，检验员 C 复测确认。
- **Which（影响对象）**：ZK-A5 接口板组件，残留物集中于连接器焊点及屏蔽罩周边缝隙区域。
- **How detected（如何检出）**：周检批次离子污染度超标 → 回溯周中批次复测 → 盐雾试验+体视/金相显微确认树枝晶。
- **How many（数量/比例）**：波及 06-10 至 06-16 期间清洗 3 个批次（P2025-0610-04、P2025-0611-03、P2025-0613-02）合计 704 块，全数筛查超标 461 块，超标率 65.5%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 浓度补加操作未按规程执行 | 排除：补液与化验记录齐全一致 |
| 机 | 配比系统及漂洗水系统状态 | **成立：自动配比计量泵漂移致浓度实测 6.8%（工艺 12±2%）；末级漂洗水电导率实测 38 μS/cm（限值 ≤10 μS/cm），树脂交换能力衰竭未判废** |
| 料 | 清洗剂批次差异 | 排除：同批物料他线使用正常 |
| 法 | 过程监控项目与频次设置 | **成立：浓度仅周化验、末级水电导率仅人工日检一次，无在线连续监控** |
| 环 | 车间温湿度异常 | 排除：记录处于受控范围 |
| 测 | 离子污染测试仪失准 | 排除：复测与比对样验证一致 |

### 4.2 5Why 分析链

盐雾后树枝晶 → 板面可溶离子残留超标（1.8 μgNaCl/cm²）→ 清洗剂浓度漂移致残留物溶解不充分，叠加末级漂洗水电导率超标引入二次污染 → 计量泵漂移与树脂衰竭均无报警、超标不联锁 → 各级水电导率无在线监测联锁、浓度未纳入日点检 → 清洗过程控制规范存在监控缺项。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 清洗剂浓度漂移至 6.8%（工艺 12±2%）、末级漂洗水电导率 38 μS/cm 超标，超标板未被工序内拦截 | 设备实测记录与浓度化验数据 |
| 流出原因 | 离子污染度为周抽检（每周一覆盖当日批次），P2025-0611-03 等周中批次不在覆盖窗口，未经测试直接转序入库 | 检验规范抽检条款 |
| 系统原因 | 清洗线各级漂洗水电导率无在线监测与联锁停线功能，超标不报警不停线；浓度配比未纳入日点检 | 《清洗过程控制规范》缺项 |

## D6 实施与效果验证

- 验证方法：返工品 100% 离子污染复测；复产后续 3 批（共 712 块）逐批抽测；抽 8 块盐雾 96 h 复验；联锁功能人为设定阈值触发试验 3 次。
- 验证数据：返工复测均值 0.82 μgNaCl/cm²、最大 1.18，全部合格；后续 3 批抽测值均 ≤1.1；盐雾后 20×/50× 显微检查无树枝晶、无腐蚀；末级水电导率在线曲线连续 ≤8 μS/cm；联锁报警停线功能 3 次触发均正常。
- 判定：连续 3 批零复发，措施有效；逐批检验转回调计划经评审批准启动。
