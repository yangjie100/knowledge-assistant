## D2 问题描述（5W2H）

- **What（什么问题）**：X-Ray 全检发现 0.8mm 节距 BGA（位号 U12，256 球）焊点空洞率最高 38%（标准 ≤25%），空洞集中于器件中心区域焊球，呈批量性分布。
- **When（何时发生）**：2025-04-17 白班 X-Ray 工位首次报警；追溯表明 04-10 生产批次起已存在 25%~35% 区间品流出风险。
- **Where（何处发生）**：SMT 回流焊工序（R2 线十温区回流炉）产生 → X-Ray 全检工位检出。
- **Who（谁发现）**：X-Ray 操作员报检，检验员 A 复判，质量工程师图像复核确认。
- **Which（影响对象）**：ZK-B2 电源模块 U12 位号 BGA 焊点，中心约 6×6 阵列焊球集中。
- **How detected（如何检出）**：X-Ray 软件报警（38% 超出当时误设的 35% 判定限）→ 图像人工复判 → 金相切片确认空洞形貌与位置。
- **How many（数量/比例）**：按 25% 标准全数复检，本批 220 块中不合格 26 块（11.8%）；追溯前批 P2025-0410-01（200 块）不合格 9 块，合计 35 块。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 印刷/贴装未按参数卡执行 | 排除：参数卡与过程记录一致，钢网清洗记录完整 |
| 机 | 回流炉温曲线异常 | **成立：实测恒温段（150~185℃）仅约 45s，升温斜率 2.1℃/s 偏快，液相前排气不充分** |
| 料 | SAC305 焊膏批次异常 | 排除：同批焊膏在对比线以含排气段曲线试焊 3 片，空洞率 8%~14%；回温/搅拌记录合规 |
| 法 | 钢网开孔与印刷参数不当 | 排除：印刷厚度 0.135±0.01mm，过程记录受控 |
| 环 | 车间温湿度异常 | 排除：23±3℃、45%~65%RH 记录在受控范围 |
| 测 | X-Ray 判定参数问题 | 成立（构成流出原因，详见 4.3）：判定阈值误设 35% |

### 4.2 5Why 分析链

- **直接原因链**：中心焊球空洞率 38% → 液相阶段助焊剂挥发气体滞留焊点内 → 恒温段溶剂挥发不充分，BGA 中心区气体排出通道不畅 → 曲线恒温段仅约 45s，缺少排气段 → 焊膏型号更新后未重新做空洞专项评定，沿用原快升温曲线。
- **流出原因链**：25%~35% 空洞品被放行 → 软件判定限为 35% 而非 25% → 04-09 软件升级时单人修改参数且无复核 → 首件也未做空洞率人工复核，未能拦截。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 回流曲线恒温排气段时间不足，无铅焊膏挥发分液相前未排出，中心焊球气体滞留成洞 | 九点炉温实测、切片空洞集中于中心焊球 |
| 流出原因 | X-Ray 判定阈值误设 35%（应为 ≤25%），首件未做空洞率人工复核 | 软件参数变更记录、首件自动判定放行记录 |
| 系统原因 | 检测设备判定参数变更无双人复核与权限锁定机制，变更未纳入受控管理 | 《检验设备管理规定》缺项、权限清单核查 |

## D6 实施与效果验证

- 验证方法：新曲线导入后连续 3 批（共 560 块）X-Ray 全检；每批抽 3 块金相切片；炉温每班实测记录。
- 验证数据：空洞率均值 11.2%、最大 18.9%，中心焊球无 >25% 案例；切片 IMC 厚度 1.5~3.0μm 均匀连续；炉温复测偏差 ≤2℃；32 块返修品复检合格。
- 判定：连续 3 批零超标，措施有效，经评审批准转入常态监控。
