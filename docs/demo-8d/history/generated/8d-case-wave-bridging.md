## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 操作员未按参数卡执行 | 排除：参数设定与运行记录一致 |
| 机 | 波峰高度异常 | **成立：实测 8.3 mm，超出工艺窗口 7.0±0.5 mm 上限** |
| 料 | 焊料成分异常 | 排除：锡炉光谱分析合格 |
| 料 | 助焊剂状态异常 | **成立：来料批次排除，但机内比重班中实测 0.831，超窗口 0.805±0.010** |
| 法 | 过程监控规则缺失 | **成立：比重点检为每周一次，无法发现班内漂移；波峰高度未纳入首件三检** |
| 环 | 车间温湿度异常 | 排除：记录处于受控范围 |
| 测 | 检出手段不足 | **成立：目检工位实测照度 520 lx，低于规定 ≥800 lx，且未配置放大镜** |

### 4.2 5Why 分析链

DIP 连接器批量桥连 → 2.0 mm 间距引脚间焊料分离不良 → 助焊剂有效涂覆量偏低（称重法折算约 36 g/m²，低于窗口 50±5 g/m²）叠加波峰高度偏高（8.3 mm）导致焊料过量上涌、回流分离差 → 助焊剂机内比重因溶剂挥发班内持续漂移、黏度上升致雾化劣化，且波峰高度漂移未在首件确认 → 比重点检周期为每周一次、波峰高度未列入首件三检清单 → 《点检规程》与《首件三检规程》未定义关键参数的班次级监控要求。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 助焊剂喷涂量偏低叠加波峰高度偏高，引脚间焊料分离不良形成桥连 | 涂覆量称重与波峰高度实测数据 |
| 流出原因 | 目检工位照度不足且未配置放大镜，桥连识别依赖检验员个人经验，漏检率高 | 工位照度实测与作业观察记录 |
| 系统原因 | 助焊剂比重点检周期为每周一次，无法捕捉班内漂移；波峰高度未纳入首件三检 | 《波峰焊过程点检规程》条款核查 |

## D6 实施与效果验证

- 验证方法：复产后连续 5 个班次共 620 块，桥连相关目检＋ICT 全检；每班抽 3 块以 10× 显微镜复核 CN5/CN8 区域；同步核查比重与波峰高度趋势记录。
- 验证数据：桥连 0 例；助焊剂比重稳定于 0.803~0.809；波峰高度记录 7.0~7.2 mm；班均返修工时回落至 0.6 h；目检工位照度实测 1050 lx。
- 判定：连续 5 个班次零复发，措施有效；复产初期全检经评审回调为正常抽检。
