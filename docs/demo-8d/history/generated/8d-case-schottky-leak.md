## D2 问题描述（5W2H）

- **What（什么问题）**：ZK-B2 电源模块经 125 ℃/48 h 满载通电老化后电测，整流肖特基二极管（位号 D5/D12）在 125 ℃ 下反向漏电流实测 443~468 μA，超规范限值（≤200 μA）约 2.2~2.3 倍，模块转换效率由规范 ≥88% 降至 84.1%~85.6%。
- **When（何时发生）**：2025-08-11 白班老化后电测工位首次检出。
- **Where（何处发生）**：老化＋电测筛选环节检出，失效溯源至 SMT 贴装的二极管供应商批次 L2507-118。
- **Who（谁发现）**：老化操作员报检，检验员 C 复判，器件工程师失效分析确认。
- **Which（影响对象）**：ZK-B2 电源模块，整流肖特基二极管 D5/D12（单供应商关键料号）。
- **How detected（如何检出）**：老化后例行电测效率项报警 → 单管 125 ℃ 反向漏电流复测 → 拆样 DPA 及 SEM 确认芯片减薄面微裂纹。
- **How many（数量/比例）**：不合格 4 只 / 同批 9 只，不合格率 44.4%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 贴装/回流未按参数卡执行 | 排除：参数卡与过程记录一致 |
| 机 | 回流焊温度曲线超差致器件损伤 | 排除：曲线峰值 245±3 ℃ 在窗口内；未上机原器件高温测试亦超限 |
| 料 | 二极管批次性高温特性劣化 | **成立：失效样品及同批未上机器件 DPA 均见减薄面微裂纹、边缘崩边** |
| 法 | 老化条件设置过严 | 排除：条件符合详细规范 |
| 环 | 老化房温度失控 | 排除：温度记录 125±2 ℃，受控 |
| 测 | 电测设备误报 | 排除：标准表复测确认真实超限 |

### 4.2 5Why 分析链

老化后反向漏电流超限 → 二极管高温反向特性劣化 → 芯片减薄面微裂纹及边缘终结区损伤 → 该批芯片减薄厚度波动超供应商内控（实测 88~112 μm，目标 100±5 μm）→ 我方来料验证仅含常温参数，高温反向特性未列入检验项，批间漂移无基线可比对。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 供应商该批次芯片减薄工艺波动，减薄面损伤致高温反向漏电流增大 | DPA/SEM 分析报告、供应商减薄厚度实测数据 |
| 流出原因 | 常温来料检验（25 ℃ IR≤10 μA）与产线常温电测均通过，高温反向特性未列入该料号来料验证项 | 《来料检验规范》相应条款缺项 |
| 系统原因 | 关键单供应商料号缺少高温参数批间比对基线库，验证项目未按器件失效机理差异化定义 | 关键料号管理程序审查记录 |

## D6 实施与效果验证

- 验证方法：换用合格批次（L2509-201，附高温测试报告）复产 3 批共 27 只，执行“老化＋电测”100% 全检；连续 2 个新到批次执行高温来料抽测并录入基线库。
- 验证数据：3 批 27 只 125 ℃ 反向漏电流实测 42~96 μA（限值 200 μA），效率 88.4%~89.6%，异常 0 例；来料抽测 2 批 40 只全部合格，批间均值 45/52 μA 已入库。
- 判定：连续 3 批零复发，高温来料抽测与基线库运行正常，措施有效。
