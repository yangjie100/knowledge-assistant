## D2 问题描述（5W2H）

- **What（什么问题）**：客户端开箱复检发现 ZK-D1 板 C23 位号片式钽电容（100μF/16V）极性反接；厂内全数复检累计确认 3 块；追溯确认 AOI 程序该料号极性检查窗口处于关闭状态，反接缺陷未被拦截。
- **When（何时发生）**：缺陷产生于 2025-02-16/17 返修工位手工补贴时段；02-24 客户端复检发现并反馈。
- **Where（何处发生）**：缺陷源为返修工位手工补贴 → AOI 检验工序（A2 线）拦截失效 → 客户端开箱复检环节检出。
- **Who（谁发现）**：客户方复检人员首检发现，厂内检验员 A 复判及全数复检确认。
- **Which（影响对象）**：ZK-D1 信号处理板，批次 P2025-0216-01，位号 C23。
- **How detected（如何检出）**：客户开箱目视＋复检 → 厂内 AOI 程序版本追溯＋全数复检。
- **How many（数量/比例）**：极性反接 3 块 / 批次总数 180 块，占 1.7%（客户端 1 块、厂内成品库 2 块）。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 夜班手工补贴极性装反 | 成立（发生源，属偶发差错，工艺设计上应由 AOI 100% 拦截） |
| 机 | AOI 相机分辨率/光源不足 | 排除：程序修复后同缺陷样本 10/10 拦截 |
| 料 | 钽电容本体极性标识不清 | 排除：标识清晰，人工复检可辨 |
| 法 | 程序版本回退无差异比对与放行清单 | **成立：系统原因** |
| 环 | 车间照明/静电干扰 | 排除：环境记录受控 |
| 测 | 程序变更后首件仅跑标准缺陷样板 | **成立：流出原因，样板未含 C23 反接样本** |

### 4.2 5Why 分析链

极性反接电容流出 → AOI 该料号极性检查窗口处于关闭状态未报警 → 02-14 程序由 V3.5 回退至 V3.4，而 V3.4 存档版本在 01-28 离线调试中该检查项被误关并随版本保存，回退时仅做整体运行确认，未执行元件级检查项覆盖比对 → 程序变更后首件验证仅运行标准缺陷样板，未核查全料号检查项开关状态 → 《AOI 程序管理办法》无版本变更差异比对与放行清单要求。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 程序回退后 C23 极性检查项参数丢失且未做元件级比对，反接缺陷未被拦截 | 程序参数导出比对记录 |
| 流出原因 | 程序变更后首件仅验证标准缺陷样板，未确认全料号开关状态，失效未被发现 | 首件验证记录 |
| 系统原因 | 《AOI 程序管理办法》无版本变更差异比对、双人放行及放行清单要求 | 文件评审确认缺项 |
