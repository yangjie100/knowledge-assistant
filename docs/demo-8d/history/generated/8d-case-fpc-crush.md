## D2 问题描述（5W2H）

- **What（什么问题）**：翻转机构 FPC 排线与钣金支架翻边边缘干涉压伤，绝缘层破损、局部导体外露，信号时通时断，功能时好时坏；3 台整机老化试验中出现黑屏。
- **When（何时发生）**：2024-07-09 夜间老化试验至 36h 温循段反馈黑屏；07-10 装配后点检针对性排查发现排线压痕，确认为同一失效模式。
- **Where（何处发生）**：部件装配工序（A5 装配线翻转机构压装工位）引入 → 装配后点检工位检出；整机老化试验室复现。
- **Who（谁发现）**：老化试验技术员报检黑屏，点检员复查发现压痕，检验员 C 复判确认。
- **Which（影响对象）**：ZK-D1 信号处理板，翻转机构 FPC 排线 FL2 与钣金支架 BM-07 翻边边缘。
- **How detected（如何检出）**：老化黑屏返修排查 → 显微检查发现排线压伤 → 断面塞尺实测排线与钣金圆角间隙 0.3mm。
- **How many（数量/比例）**：老化 8 台中 3 台黑屏（37.5%）；全批 80 块复测，间隙 0.3~0.6mm，全部低于设计要求 ≥1mm，其中 12 块目视可见压痕。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 压装未按 SOP 定位、用力过猛 | 排除：压装压力与定位记录一致 |
| 机 | 压装工装定位销磨损 | 排除：工装复测定位偏差 ≤0.05mm |
| 料 | FPC 排线厚度超差 | 排除：实测 0.33mm，规格 0.3±0.05mm |
| 料 | 钣金翻边圆角实测 R0.5，图纸要求 R1 | **成立（贡献因子）：尖边加剧压伤** |
| 法 | 排线路径间隙公差累积未分析 | **成立（主因）：名义间隙 1.2mm，累积最坏 -0.9mm 后仅余 0.3mm** |
| 环 | 车间温湿度影响 | 排除：环境记录在受控范围 |
| 测 | 装配后仅做功能测试 | **成立（流出）：隐性压伤在振动/温循后才显现** |

### 4.2 5Why 分析链

整机黑屏 → FPC 排线导体压伤后时断时通 → 排线与钣金翻边间隙仅 0.3mm，公差累积后干涉（钣金折弯 ±1° 折算 ±0.4mm、FPC 弯折高度 ±0.3mm、支架安装孔位置度 0.3mm，叠加方向最坏）→ 设计时未对排线路径开展公差累积分析 → 新研产品设计评审未将装配路径干涉检查列为强制项。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 排线路径与钣金圆角间隙实测 0.3mm（设计要求 ≥1mm），公差累积叠加 R0.5 尖边导致压伤 | 全批间隙实测数据与断面分析报告 |
| 流出原因 | 装配后仅做功能测试，压伤为隐性损伤，施加振动/温循应力后才显现，产线现有手段无法检出 | 检验规范与工位检测能力清单 |
| 系统原因 | 新研产品设计评审强制项未包含装配路径干涉与公差累积分析 | 《设计评审管理办法》条款核查 |

## D6 实施与效果验证

- 验证方法：隔离的 80 块全数返工（更换新版钣金 80 件、护线胶套 80 套、损伤排线 12 根），返工后 100% 间隙实测 + 100% 老化；复产后续 3 批共 150 块按 D5-3 执行 100% 老化，并抽 10 块拆解目检。
- 验证数据：返工件间隙实测 1.5~1.8mm 全数合格；老化（40h 温循 + 随机振动）黑屏 0 例；拆解抽检排线无压痕，护线胶套无位移、无脱落。
- 判定：连续 3 批零复发，措施有效；该型号量产阶段老化覆盖率按规范维持 100%，不回调。
