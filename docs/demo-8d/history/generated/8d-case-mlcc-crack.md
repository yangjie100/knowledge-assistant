## D2 问题描述（5W2H）

- **What（什么问题）**：高温老化（70 ℃/72 h）后电测发现 0402 电容容量衰降超 30%，金相切片确认弯曲裂纹贯穿介质层。
- **When（何时发生）**：2024-08-19 白班老化后电测工位首次检出。
- **Where（何处发生）**：分板＋装配工序引入缺陷 → 老化＋电测工序检出。
- **Who（谁发现）**：电测操作员报检，检验员 A 复判确认。
- **Which（影响对象）**：ZK-A5 接口板组件，V 槽分板长边邻近位号 C15/C22/C31 的 0402 电容（100 nF）集中。
- **How detected（如何检出）**：电测容量偏低下限报警 → 容量复测确认衰降 → 金相切片定位裂纹源。
- **How many（数量/比例）**：不合格 5 块 / 批次总数 150 块，不合格率 3.3%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 分板手工辅助掰板操作不当 | 排除：操作记录与作业指导书一致 |
| 机 | V 槽分板应力过大 | **成立：应变片实测分板边焊点应变峰值 920 με，超出阈值 600 με** |
| 料 | 电容本体抗弯强度批次差异 | 排除：同批电容远离分板边位号切片无裂纹 |
| 法 | Layout 应力敏感件布局无距离/取向约束 | **成立：电容长轴平行分板边且距边仅 1.2 mm** |
| 环 | 车间温湿度异常 | 排除：环境记录受控 |
| 测 | 电测容量容差 ±20%，老化后无复测工序 | **成立：30% 衰降处于边界漏检区间** |

### 4.2 5Why 分析链

容量衰降超 30% → 弯曲裂纹贯穿介质层 → V 槽分板应力经焊点传导至电容本体 → 电容长轴与分板边平行且距边 1.2 mm（最不利取向）→ 应力敏感件布局规则未纳入 DFM 自动检查，设计端无法拦截。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | V 槽分板应力传导至邻近电容，最不利取向致裂纹贯穿介质层 | 应变实测数据与切片形貌 |
| 流出原因 | 电测容量容差 ±20%，30% 衰降处于边界漏检区间；老化后无容量复测 | 电测程序设定与流程文件 |
| 系统原因 | Layout 规范无应力敏感件距边距离/取向规则，DFM 无自动检查项 | 《PCB Layout 设计规范》缺项 |

## D5 永久纠正措施（PCA）

| 序号 | 针对原因 | 措施 | 责任 | 期限 |
|---|---|---|---|---|
| 1 | 直接原因 | Layout 改版：涉事 0402 电容长轴垂直于分板边，距边 ≥3 mm（实测 3.5 mm），设计文件升版 | 设计室 | 09-10 |
| 2 | 直接原因 | 分板改为铣刀式低应力设备（主轴 45000 r/min、进给 25 mm/s），工艺文件升版并首件鉴定 | 工艺室 | 09-20 |
| 3 | 流出原因 | 老化后增设容量复测工序，控制限收紧至 ±10%，纳入电测程序 | 质量部 | 09-15 |
| 4 | 系统原因 | 规范增补应力敏感件布局规则，DFM 检查软件增加自动判项并纳入设计评审 | 设计室 | 09-30 |

## D6 实施与效果验证

- 验证方法：改版后连续 3 批（共 450 块），分板后应变片测试 + 70 ℃/72 h 老化后容量复测全检，每批抽 5 块金相切片。
- 验证数据：分板边焊点应变峰值由 920 με 降至 260 με；容量衰降全部 ≤3%；切片 0 裂纹；容量复测 0 不合格。
- 判定：连续 3 批零复发，措施有效，老化后容量复测工序转入常规控制。
