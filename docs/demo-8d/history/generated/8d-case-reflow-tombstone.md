## D2 问题描述（5W2H）

- **What（什么问题）**：回流焊后 AOI 检出 0402 封装片式电容批量立碑（元件一端脱离焊盘竖立翘起），显微复判属实。
- **When（何时发生）**：2024-05-20 白班 10:35，AOI 批量报警触发停线报检。
- **Where（何处发生）**：SMT 回流焊工序（R2 工位）→ 回流焊后 AOI（A2 检测机）检出。
- **Who（谁发现）**：AOI 操作员报警报检，检验员 30 倍显微复判确认并升级质量部。
- **Which（影响对象）**：ZK-B2 电源模块，同一炉次 25 块板；47 处立碑中 43 处集中于距板边 15 mm 以内的 C2xx 位号区。
- **How detected（如何检出）**：AOI 立碑/偏移算法报警 → 人工显微复判 → 炉温测试仪实测曲线复核。
- **How many（数量/比例）**：不合格板 12 块 / 炉次总数 25 块（占 48%）；立碑缺陷 47 处，该炉次 0402 点位立碑率约 1.0%。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 贴片偏移或贴装压力异常 | 排除：贴片首件记录与抽检 CPK 正常 |
| 机 | 回流焊炉温曲线异常 | **成立：实测预热区升温斜率 3.2 ℃/s，超出工艺文件规定 1.5～3.0 ℃/s 上限** |
| 料 | 焊膏过期、回温或搅拌异常 | 排除：同批焊膏他线使用正常，记录合规 |
| 法 | 焊盘两端热容不对称 | **成立：板边 0402 焊盘一端经导通孔与大铜面相连，两端热容差约 35%** |
| 环 | 车间温湿度波动 | 排除：环境监测记录在受控范围 |
| 测 | AOI 误判 | 排除：47 处报警经显微复判均为真实立碑 |

### 4.2 5Why 分析链

电容立碑 → 焊膏两端熔融不同步，先熔融端表面张力将元件另一端拉起 → 预热区升温过快叠加焊盘两端热容不均，小热容端焊膏先达熔点 → 炉程序被更换为未经评审的 V2.4 曲线（05-16 为处理其他型号连锡临时调整后未恢复）→ 曲线变更无评审签批流程，炉程序权限未分级管控 → 工艺文件（规定 V2.3 曲线）与炉程序版本缺少同步核对机制。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 预热区升温斜率 3.2 ℃/s 偏快，叠加板边焊盘两端热容不均，焊膏一端先熔融、表面张力失衡致立碑 | 测温板实测＋红外热像＋焊盘热容核算 |
| 流出原因 | AOI 立碑高度判定阈值偏宽（+45%），首件确认仅覆盖板中心 3 个检测窗，板边区域未纳入 | AOI 程序参数记录、首件确认记录 |
| 系统原因 | 《回流焊工艺管理办法》未规定曲线变更评审签批与文件/炉程序版本同步要求，炉程序权限开放 | 体系文件审查、炉程序变更日志 |

## D6 实施与效果验证

- 验证方法：措施后连续 3 个炉次（共 75 块板）AOI 全检＋板边 0402 专项显微抽检（每炉 3 块×30 点）；每班炉温实测记录复核。
- 验证数据：立碑缺陷 0 处；预热区斜率实测 2.0～2.2 ℃/s；AOI 新阈值对历史缺陷样本检出率 100%，良品误报率 0.5%（1/200）；首件记录完整覆盖四角＋中心 5 点区域。
- 判定：连续 3 个炉次零复发，措施有效；AOI 阈值回归验证通过后正式发布生效。
