## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 操作未按参数卡执行 | 排除：参数卡与记录一致 |
| 机 | 锡炉温度漂移 | **成立：实测 242 ℃，低于工艺窗口 250±5 ℃** |
| 料 | 焊锡条/助焊剂批次差异 | 排除：同批物料他线使用正常 |
| 法 | 工艺窗口设置不合理 | 排除：窗口经工艺评定 |
| 环 | 车间湿度异常 | 排除：记录在受控范围 |
| 测 | 电测夹具误报 | 排除：复判与切片证实真实虚焊 |

### 4.2 5Why 分析链

网络开路 → 焊点虚焊 → 焊料润湿不足 → 锡炉实际温度偏低（242 ℃）→ 温控热电偶老化漂移 → 设备点检未覆盖热电偶校准周期。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 锡炉温度低于工艺窗口下限，润湿不良 | 点检记录与实测数据 |
| 流出原因 | 电测按 AQL 抽检，未能在工序内全数拦截 | 检验规范条款 |
| 系统原因 | 设备点检规程未包含热电偶校准周期要求 | 《设备点检规程》缺项 |

## D6 实施与效果验证

- 验证方法：复产后续 3 批（共 360 块）电测全检 + 每批抽 5 块金相切片。
- 验证数据：开路不良 0 例；切片焊点润湿角合格率 100%；锡炉温度连续记录处于 250±3 ℃。
- 判定：连续 3 批零复发，措施有效，D5-2 检验回调经评审批准。
