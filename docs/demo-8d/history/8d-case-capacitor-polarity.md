## D2 问题描述（5W2H）

- **What（什么问题）**：电源模块老炼试验后 2 块出现电解电容鼓包失效，追溯确认为电容极性反装。
- **When（何时发生）**：2026-05-06 老炼间巡检发现。
- **Where（何处发生）**：插件工序（W5 工位）装反 → 老炼工序暴露。
- **Who（谁发现）**：老炼操作员报检，检验员 C 确认。
- **Which（影响对象）**：ZK-B1 电源模块 C12/C15 位号电解电容。
- **How detected（如何检出）**：老炼后外观巡检发现鼓包 → 位号核对确认极性反。
- **How many（数量/比例）**：鼓包失效 2 块；全批复检另发现反装未失效 3 块，合计 5 块 / 80 块。

## D4 根本原因分析

### 4.1 鱼骨图分析（5M1E）

| 类别 | 疑点 | 排查结论 |
|---|---|---|
| 人 | 操作员凭记忆插装未核对丝印 | **成立：作业观察证实** |
| 机 | 无极性防错工装 | **成立：依赖人眼识别** |
| 料 | 电容本体极性丝印颜色浅、可辨识度差 | **成立：来料实物比对** |
| 法 | SOP 图示小、极性标识不醒目 | **成立：文件核查** |
| 环 | 工位照明照度不足 | 排除：实测达标 |
| 测 | 电测与目检均无极性判定项 | **成立：检验规范缺项** |

### 4.2 5Why 分析链

电容极性反装 → 操作员凭记忆插装未核对本体丝印 → 丝印标识颜色浅辨识困难且 SOP 图示不醒目 → 来料检验规范未包含标识可辨识度检验项 → 供应商变更印刷工艺未走 ECN 通知。

### 4.3 原因判定

| 类别 | 原因 | 判定依据 |
|---|---|---|
| 直接原因 | 插装极性标识视认性差（料+SOP 叠加） | 实物与文件核查 |
| 流出原因 | 目检与电测均未设极性判定项 | 检验规范条款 |
| 系统原因 | 供应商变更管理（ECN）流程对标识类变更未覆盖 | 变更记录追溯 |

- 验证方法：措施落实后连续 2 批（160 块）电测全检 + 极性专检双确认。
